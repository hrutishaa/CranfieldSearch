CranfieldSearch

A search engine written from scratch in Java (inverted index, Porter stemmer, BM25), run here over the 1,400 Cranfield aerodynamics abstracts. The index is built by the Java code and exported to JSON; this page ranks with the same BM25 formula in your browser.
